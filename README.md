# 原子スペクトル 輝線 波長 可視化ツール

原子の輝線スペクトルをバルマー系列式等で計算しCanvas可視光スペクトルバー上に可視化する分光学教育ツール。

## 機能

- 水素・ヘリウム・ナトリウム・水銀・ネオン・カルシウムの輝線スペクトル表示
- 水素はリドバーグ式でライマン/バルマー/パッシェン/ブラケット系列を計算
- 波長→RGB変換によるリアルなスペクトルバー描画
- Canvas による水素エネルギー準位図と量子遷移矢印
- UV/NIR 領域の表示切替、波長ラベル表示オプション
- 輝線一覧テーブル（量子数・エネルギー・相対強度）

## 技術メモ

- リドバーグ式: 1/λ = R∞(1/n₁² − 1/n₂²), R∞ = 1.0974×10⁷ m⁻¹
- 波長→RGB: CIE等色関数近似による可視光マッピング
- 単体 HTML + Tailwind CDN
